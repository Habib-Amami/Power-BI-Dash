Designing an Interactive Dashboard with

Power BI

I. Project Objective
The objective of this mini-project is to use Power BI to collect, transform, analyze, and visualize data within an interactive dashboard. The goal is to assist a user (such as a manager, or someone in marketing, HR, finance, etc.) in making decisions based on Key Performance Indicators (KPIs).
II. Tasks to be completed:
This project can be divided into four parts:
1. Data Collection and Preparation
 Importing one or more files (Excel, CSV, databases, etc.).
 Cleaning and transforming data using Power Query (removing duplicates, handling missing values, creating custom columns, etc.).
 Data modeling (defining tables and the relationships between them, such as a star schema).
Note: Here are some websites where you can download datasets:
https://www.kaggle.com/datasets
https://solutions.lesechos.fr/tech/data-stockage/12-datasets-gratuits-pour-s-exercer-a-power-bi
2. Creating Indicators and DAX Measures
 Creating measures (e.g., total sales, growth rate, monthly average).
 Creating calculated columns where necessary.
 Implementing the project’s key KPIs.
3. Dashboard Design
 Selecting relevant visualizations (bar charts, cards, matrices, gauges, line charts, etc.).
 Formatting the report (themes, colors, layout).
 Adding filters and slicers.
 Creating report pages: Overview, Details, and In-depth Analysis (optional).
III. Deliverables
 The complete Power BI file (.pbix)
 Datasets used
